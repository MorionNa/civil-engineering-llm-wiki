# GLM 水利水电行业大模型 — 汇报笔记

> 来源：2026年 GLM 大模型在水利水电行业的应用汇报（PPT 拍照识别）
> 核心合作方：智谱AI + 清华大学 + 国能大数据 + 大渡河公司

---

## 一、总体技术路线：GLM L0 → HydroGLM L1 → 应用 L2

```
基础设施层 (GPU + Data + Algorithm)
  ↓
L0 基础大模型：GLM（语言+多模态+时序）
  ↓
L1 行业大模型：HydroGLM (Flash/Plus)
  ↓
L2 场景应用：
  ├── 工业场景：气象水文预报 / 流域调度 / 工程安全监测
  │              设备检修 / 施工管理
  └── 科研(AI4S)：AI建模工具 / AI专业模型
         ↑
    智能中台 (HydroGLM Platform) — MaaS平台
```

**关键策略**：国产自主可控（GLM），"L0通用→L1行业→L2场景"三层递进。

## 三、构建范式：成本-质量四层漏斗

```
低成本/低质量
  → ① Prompt Engineering（提示工程 + 上下文）
  → ② RAG（检索增强生成：向量库 + 文档检索）
  → ③ Fine-Tuned Model（微调：QA对训练，知识内化）
  → ④ Trained Model（从头训练垂直行业模型）
高成本/高质量
```

**本项目定位**：以 ③（微调）为核心，辅以 ②（RAG）和 ①（提示工程），目标是用有限成本达到行业可用水平。

### 5.2 教材覆盖的学科（1023本）

- 电气工程（电力系统分析、电机学、高压电工程）
- 水力学及河流动力学（工程流体力学、河流动力学概论）

- 数据分布：能源电力 > 水利水电工程 > 水文 > 信息化 > 水资源 > 水土保持 > 农村水利

### 5.4 学科方向分布

水利水电工程 / 水文学及水资源 / 水力学及河流动力学 / 流域环境生态科学与工程 / 大气科学（水文方向）/ 电气工程（水电方向）

## 六、研发流程：三阶段有序推进

### 第一阶段：前期规划与数据准备
- 场景任务规划 → 业务线划分 → 功能需求清单
- 资料清单梳理 → 数据集目录 → 数据分层分级
- 行业公开数据 + 企业内部数据 → 水电多类型语料数据库

### 第二阶段：模型训练与评估
- 预训练语料预处理 → SFT问答对生成（10000条）→ 问答对校验
- 时序数据整理 → 时序模型微调 → 时序大模型初评
- 模型二次微调 → 预训练模型评价 → 通识能力 + 场景任务能力评价
- 评测标准库 → 微调效果判断 → 迭代优化

### 第三阶段：应用开发与上线
- 水电大模型应用原型 → 业务部门讨论 → 高级接口/交互应用
- 模型调优（提示工程 + RAG）→ 标准评测 + 真实场景测试 → 正式上线

## 七、评测体系：22项指标 + A/B卷分级 + 性能数据

### SFT 数据规模
- 总训练数据：**577 万条**
  - 领域数据 60.5 万（COT 推理 48 万 + 知识/阅读 12.4 万）
  - 通用数据 516.4 万（含 DeepSeek-R1 数学推理 13 万 + 通用任务 500 万）
- 两轮增量预训练 + 多轮多策略 SFT

### 评测结果：HydroGLM vs DeepSeek-V3/R1

| 模型 | 总体 | 大气科学 | 水利工程建设 | 工程管理 | 背景知识 | 水力学 | 水文水资源 | 水电运维 | 生态环境 | 电气工程 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| DeepSeek-V3 | 74.9 | 75.0 | 79.1 | 82.0 | 77.1 | 70.8 | 78.2 | 68.1 | 60.7 | 80.8 |
| DeepSeek-R1 | 78.5 | 69.6 | 85.0 | 84.1 | 83.3 | 77.9 | 87.6 | 75.4 | 70.0 | 77.2 |
| **HydroGLM** | **88.6** | **88.3** | **92.5** | **90.6** | **90.6** | **89.1** | **86.0** | **92.0** | **81.8** | **86.5** |

> **HydroGLM 在全部 9 个领域全面碾压 DeepSeek 系列，总体领先 10-14 分。** 轻量化设计便于业务落地。

### 四大维度

| 维度 | 核心指标 |
|------|---------|
| **功能** | 任务规划与执行、数据分析与预测、图像处理、因果推理、知识问答 |
| **安全** | 调规运规遵守、企业隐私安全、敏感数据加密、权限控制、水电规程 |
| **性能** | F1指标、首字响应时间、处理效率、正确性、相关度 |
| **质量** | 内容相关性、专业准确性、可读性、可靠性(MTBF)、可维护性 |

**可靠性公式**：MTBF = F / T（F=时间段T内故障次数，故障定义=因模型自身原因导致≥1分钟无返回）

**安全审查表**：三级评分（禁止/问题/无问题），覆盖敏感话题、歧视、安全合规等

## 八、智能体中台（"瀚海" HydroGLM Platform）

### 核心组成
- **GLM5.1 系列基础大模型** + L1水利水电行业大模型（双引擎）
- **1.3TB 工程专用检索增强知识库**（教材+期刊+规范+法规）
- **76 个领域专用工具**（数据处理、经典公式计算、指标分析评价）
- **SKILL 生成器**：业务需求 → 智能体 Skill 自动编排
- **底座大模型集群**：DeepSeek / Qwen / LLaMA 等可接入

### 四阶段闭环
1. **业务需求录入**：自然语言 + IDE编排 → 自动生成 Skill 逻辑框架
2. **业务知识内化**：作业指导书/调度规程 → 自动解构 → 结构化 Skill
3. **任务精准执行**：References（专业规则）+ Python Scripts 双驱动
4. **经验资产复用**：逻辑描述 + 参考文档 + 脚本 → 可复用 Skill 组件

### 覆盖领域
水利水电工程 / 能源动力 / 建筑工程 / 交通地质测绘 / 电气工程 / 生态环境安全 / 建筑结构与施工 / 工程通用知识
