# Cycle 22 PCIL review: NO-GO

PCIL passed its focused implementation suite but failed Sol's remote
authorization audit. Its common-descent proxy is circular because its teacher
is the same PCIL architecture with manually perturbed weights. The active
halo path is not tested with nonzero projections, the edge projection bypasses
the pre-block representation, and the port feature is not orientation- or
degree-invariant.

No remote experiment is authorized. Keep the frozen parent and V21 fallback;
do not revive this PCIL implementation without a new design decision.
