# OPSF M0 review — 2026-08-03

OPSF (Orthogonal Plugin-State Flow) was screened after RPSL and BCPA. Its local skeleton reused the repository's scalar linear, bilinear, and Bouc–Wen step laws and passed seven focused tests, but the implementation failed the stricter contract audit.

The decisive issue is temporal: the adapter evaluates the law with identical current and next kinematics, then the learned acceleration proposal changes the kinematic endpoint without an authoritative constitutive evaluation and hard-EOM recomputation at that endpoint. This is a local semantic failure, not a GPU numerical failure.

The scalability claim also fails in the current code because each step materializes a dense incidence matrix and because the generic matrix-plugin path can bypass edge-force assembly. No remote preflight was run.

Disposition: NO-GO. Retain the parent/V21 fallback and require endpoint constitutive semantics, sparse matrix-edge scatter, owner/ghost partition checks, and long-rollout stability before another remote experiment.
