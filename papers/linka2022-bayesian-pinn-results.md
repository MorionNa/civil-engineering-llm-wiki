## 逐模型详细发现

### NN（纯神经网络）
- **训练集：** 良好拟合 2021 年 COVID-19 数据
- **测试集/外推：** 预测质量急剧下降——无物理约束 → 无法捕捉季节性振荡模式
- **结论：** 纯黑箱模型不适合动力系统外推预测

### PINN

#### ε 网格搜索结果
PINN 性能对权重系数 ε 高度敏感：

- 固定 ε 下搜索 6 个值：ε ∈ [10⁻∞, 10⁻⁵, 10⁻⁴, 10⁻³, 10⁻², 10⁰]
- 最优 ε = 10⁻³ 时：训练拟合好，预测好，物理参数收敛到合理值
- ε = 0（纯数据）→ 退化为 NN，外推差
- ε = 1（纯物理）→ 无法拟合数据波动

#### 物理参数反演（ε = 10⁻³ 时）
- 阻尼 c = 1.251
- 刚度 k = 374.6
- 偏移 x₀ = 0.558
- 衰减率 δ = 0.626
- 固有频率 ω = 19.35
- 周期 T = 0.325 年

**解释：** COVID-19 疫情呈周期性振荡，约每 4 个月一个波峰，衰减趋势反映群体免疫和防控效果。

#### ε 敏感性分析
- Loss landscape 在低 ε 和高 ε 之间存在数量级差异
- $L_{data}$ 和 $L_{phys}$ 随 ε 变化呈反比趋势：ε 增大 → $L_{phys}$ 减小但 $L_{data}$ 增大
- **没有天然的最优 ε**，需网格搜索或自适应机制

### SAPINN
- 自适应 ε(t) 在训练过程中自动收敛到合理值
- 即使在小训练集（少量数据点）下仍保持良好预测能力
- 避免了 PINN 的 ε 网格搜索开销
- 与 PINN 最优 ε 手动选择的结果相当甚至更优

### BI（纯贝叶斯推理）
- **参数后验：**
  - c = 1.111 ± 0.126
  - k = 402.4 ± 1.7
  - x₀ = 0.541 ± 0.002
- 衍生参数：δ = 0.556，ω = 20.06，T = 0.313
- **结论：** 仅 3 个物理参数即可获得不错的预测能力和紧致的后验分布——简单物理模型对 COVID-19 趋势有惊人的解释力

### BNN
- 网络权重后验提供预测可信区间
- 但无物理约束 → **可信区间在训练数据覆盖范围外不准确**
- 可信区间在插值区有效，但在外推区急剧变宽（模型意识到自己不知道）
- **关键洞察：** 可信区间宽 ≠ 可靠；在无物理约束时，BNN 的"诚实"（区间变宽）比 NN 的盲目自信更好，但仍不能替代物理信息

### BPINN（本文核心方法）

#### 物理参数后验
- c = 1.312 ± 0.391
- k = 319.4 ± 38.6
- x₀ = 0.571 ± 0.020
- 衍生参数：δ = 0.65，ω = 17.87，T = 0.352

#### 与 BI 对比
| 参数 | BI | BPINN | BPINN 不确定性 |
|------|-----|-------|:---:|
| c | 1.111 ± 0.126 | 1.312 ± 0.391 | ~3× BI |
| k | 402.4 ± 1.7 | 319.4 ± 38.6 | ~23× BI |
| x₀ | 0.541 ± 0.002 | 0.571 ± 0.020 | ~10× BI |

**分析：** BPINN 的物理参数后验方差显著大于 BI。原因：(1) BPINN 同时推断网络权重和物理参数，存在可辨识性问题；(2) 网络可以"吸收"部分物理效应。BI 更简单的模型结构（无网络）使得参数推断更紧致。

#### 预测性能
- 训练数据拟合：好（与 PINN 相当）
- 预测/外推：中等——优于 NN/BNN，但不如 BI/SAPINN
- 可信区间：完整覆盖训练数据，但在外推区变宽
- 计算时间：**6 种方法中最慢**

## 关键图表解读

### 训练数据量敏感性
- BI 和 SAPINN 在小训练集（如仅前 3 个月数据）下仍表现良好
- BPINN 需要更大的训练集才能获得稳定后验——小数据下预测能力迅速退化
- NN 和 PINN 随训练数据减少性能单调下降

### 物理参数后验分布
- BI 后验：窄峰，强证据
- BPINN 后验：宽峰，反映网络权重和物理参数之间的不确定性交易

### 预测不确定性的时间演化
- 插值区（训练时间窗口内）：所有贝叶斯方法可信区间窄
- 外推区：BPINN 区间变宽且覆盖真值（比 BNN 好），BI 区间最窄

## 模型选择决策树

```
需要不确定量化？
├── 否 → 数据多？ → 可用 NN
│                → 数据少/需外推？ → SAPINN ✅
└── 是 → 需要网络表达能力？
        ├── 否 → BI ✅ (简洁、参数少、紧致后验)
        └── 是 → 数据充足 + 算力充足？
                ├── 是 → BPINN (完整 UQ + 网络能力)
                └── 否 → 不推荐 BPINN
```
