# On Superconvergence of Runge-Kutta Convolution Quadrature

论文分析声软散射波动方程的 RK-CQ，比较标准输入和对输入求时间导数的公式，证明后者在特定 Laplace 算子界、几何和数据正则性下获得更高收敛阶。^[raw/papers/melenk2021-rkcq-superconvergence.pdf]

它提醒本项目：高阶 RK-CQ 的实际阶数不仅由经典阶决定，还受阶段阶、频域算子增长率和输入兼容条件限制。因此不能把“换成高阶 RK”直接等同于加速度 oracle 必然提高。
