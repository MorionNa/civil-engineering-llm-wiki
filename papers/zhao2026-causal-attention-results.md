# CA 实验结果详情

## 1. 1D Allen-Cahn 方程 — 标准 Benchmark

### 1.1 方程

```
u_t - 0.0001 u_xx + 5u³ - 5u = 0,  (t,x) ∈ [0,1]×[-1,1]
u(0,x) = x² cos(πx)
Periodic BC
```

### 1.2 标准 PINN 收敛过程（三阶段）

作者用 6×128 MLP + tanh，300k Adam iterations，揭示了标准 PINN 的三个阶段：
1. **<70k** iterations：完全不收敛
2. **70k–150k**：开始收敛但很快陷入平台
3. **>150k**：加速收敛，最终 L² 误差 9.02e-2

五次独立实验平均 **3.86 ± 3.12e-1**——方差极大，随机种子决定成败。

### 1.3 消融实验（同一随机种子）

| 配置 | 架构 | FF | CA | Resampling | L² 误差 |
|------|------|----|----|-----------|---------|
| (a) 标准 PINN | MLP 6×128 | — | — | — | 9.02e-2 |
| (b) + 增强 | mMLP 6×128 | m=10 | — | — | 3.30e-4 |
| (c) + CA | mMLP 6×128 | m=10 | ϵ=1000 | — | 3.99e-5 |
| (d) + CA+Resampling | mMLP 6×128 | m=10 | ϵ=1000 | ✓ | **1.40e-5** |
| (e) + CA (m=5) | mMLP 6×128 | m=5 | ϵ=1000 | — | 1.51e-5 |
| (e) + Resampling | mMLP 6×128 | m=5 | ϵ=1000 | ✓ | 1.38e-5 |

### 1.4 关键发现

- **CA 带来一个数量级提升**：3.30e-4 → 3.99e-5
- **重采样再提升约 50%**：3.99e-5 → 1.40e-5
- **减少 Fourier 特征 (m=10→5)+ 提高学习率 (lr=0.005)** 提升稳定性，全局误差不再低于初始误差（正常现象）
- 五次独立实验 CA 最佳结果与 causal PINN [17]、SA [28]、RBA [30]、BRDR [31] 对比达到 **SOTA**

## 2. 1D Korteweg-de Vries 方程 (短时间)

### 2.1 方程

```
u_t - u·u_x + 0.0025 u_xxx = 0,  (t,x) ∈ [0,1]×[-1,1]
u(0,x) = cos(πx)
Periodic BC
```

### 2.2 轻量配置

4×50 MLP，m=1 Fourier，100k iterations，**仅训练单一网络覆盖整个时域**（vs Penwarden 10 段时间推进）。

- L² 误差 **1.14e-2**，训练时间 **605s**
- 超越 Penwarden 最优结果（1.43e-2, 780s）— 更准且更快

### 2.3 增强配置

5×256 mMLP, m=2 Fourier, w_ic=500, 300k iterations：

- L² 误差 **7.26e-5**（单网络）
- + 重采样：**4.82e-5**，最大误差从 1.4e-3 → 2.0e-4
- + 5% 时间域外延：**4.03e-5**，最大误差再减半 → 1.0e-4

### 2.4 与 s-d PINN [21] 对比

| 方法 | 时间分片 | L² 误差 | 训练时间 |
|------|---------|---------|---------|
| s-d PINN 原版 [21] | 10 段 | 1.43e-2 | ~780s |
| s-d PINN 强化版 | 10 段 | 6.18e-3 | — |
| **CA (轻量)** | 1 段 | **1.14e-2** | **605s** |
| **CA (增强+重采样+外延)** | 1 段 | **4.03e-5** | — |

CA 在单段时间训练下取得更优精度。

## 3. 1D Korteweg-de Vries 方程 (长时间)

时间域 [0,5]，分 5 段时间推进。

| 配置 | 训练 | L² 误差 |
|------|------|---------|
| Penwarden [21] 最优 | 7493s | 5.15e-2 |
| Penwarden [21] 最快 | 3566s | 1.84e-1 |
| **CA 轻量 (4×50 MLP, 5 段)** | **3239s** | **3.14e-2** |
| **CA 增强 (5×256 mMLP, 5 段, 1200k)** | — | **6.52e-4** |

轻量配置即超越 Penwarden 最准 + 最快的双重记录。误差下界沿时间 slab 单调增长反映误差累积的精度壁垒。

## 4. 1D Kuramoto-Sivashinsky 方程 (混沌)

```
u_t - 5u·u_x + 0.5u_xx + 0.005u_xxxx = 0
u(0,x) = -sin(πx), Periodic BC
```

| 方法 | 时间分片 | 总迭代 | L² 误差 |
|------|---------|--------|---------|
| Wang et al. [17] | 10 段 | 2000k | ~10⁻⁴ |
| **CA** | **5 段** | **1500k** | **2.02e-4** |

- 仅用 Wang 的一半时间分片、75% 迭代量即达到可比精度
- 混沌行为下**网格采样优于随机采样** → 不启用重采样
- 最大误差在时间域中部（溶液特征先收敛后发散），单网络无法跨越整个区间

## 5. 2D Allen-Cahn 方程

```
u_t - 0.01² Δu + 5u³ - 5u = 0,  (t,x,y) ∈ [0,1]×[-1,1]²
u(0,x,y) = cos(πx)cos(πy)(1 - e^{-(x²+y²)})
```

| 配置 | L² 误差 | 提升 |
|------|---------|------|
| mMLP 基线 | 3.34e-3 | — |
| + CA | 1.16e-3 | **+188%** |
| + CA + Resampling | **7.24e-4** | 再 +60% |

混合初始点采样策略：固定网格 64×64 + 10,000 随机点（纳入重采样过程）。

## 6. 3D Allen-Cahn 方程

```
u_t - 0.01² Δu + 5u³ - 5u = 0,  (t,x,y,z) ∈ [0,1]×[-1,1]³
u(0,x,y,z) = cos(πx)cos(πy)cos(πz)(1 - e^{-(x²+y²+z²)})
```

| 配置 | L² 误差 | 提升 |
|------|---------|------|
| mMLP 基线 | 6.88e-3 | — |
| + CA | 3.97e-3 | **+73%** |
| + CA + Resampling | **2.85e-3** | 再 +39% |

- 三维解演化出陡梯度界面（γ=0.01 对应界面宽度 ~0.01）
- 网格粗采样 32³ = 32,768 点 + 20,000 随机点
- Fourier 特征限于 m=1（Nyquist 约束）
- CA + 重采样在**不陷入维度灾难**的前提下有效改善收敛

## 7. 次优案例：1D Burgers 方程

```
u_t + u·u_x - (0.01/π)u_xx = 0
u(0,x) = -sin(πx),  u(t,±1)=0
```

| 方法 | L² 误差 |
|------|---------|
| mMLP | 8.44±11.5e-4 |
| SA [28] | 4.80±1.01e-4 |
| RBA [30] | 8.22±2.33e-4 |
| BRDR [31] | **1.38±0.85e-4** |
| CA | 3.11±0.66e-4 |

CA 在 Burgers 上次优——因为 Burgers 的激波解保持唯一稳态，初值小扰动不影响长期行为。这验证了 Turinici [23] 的理论：**指数衰减权重仅对初值敏感/混沌问题最优**。误差集中在激波捕捉（CA 不做空间自适应加权）。
