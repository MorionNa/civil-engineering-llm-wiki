# NAGO 方法机制详解

> 核心：层次化图搜索空间 HNAG + 低维连续参数化 + 贝叶斯优化搜索策略

## 5.1 层次化图搜索空间 (HNAG)

HNAG 是一个**三级层次有向图**（图 1），每一级都是一个独立的随机图生成模型。这一设计与 [[randomly-wired-networks]] 的 RNAG 形成鲜明对比——RNAG 是平面三级图，而 HNAG 是层次化嵌套图。

### 顶层 (Top Level) — Stage Graph
- **模型**：Watts–Strogatz (WS) 随机图
- **超参数**：`θ_top = [N_t, K_t, P_t]`
  - `N_t ∈ [3,10]`：stage 节点数
  - `K_t ∈ [2,5]`：环拓扑中每个节点的最近邻数
  - `P_t ∈ [0.1, 0.9]`：边重连概率
- **含义**：每个节点代表一个 cell，节点间连接代表不同 stage 之间的信息流动
- **关键特性**：允许跨 stage 的长短距离连接混合（如节点 1 和 4 同时流向节点 7），打破了传统 CNN 的纯前馈限制

### 中层 (Mid Level) — Cell Graph
- **模型**：Erdős–Rényi (ER) 随机图
- **超参数**：`θ_mid = [N_m, P_m]`
  - `N_m ∈ [1,10]`：cell 内节点数
  - `P_m ∈ [0.1, 0.9]`：边创建概率
- **为什么用 ER 而非 WS**：ER 模型允许 `N_m = 1`（单节点 cell），此时 HNAG 退化为两级结构，可以表达 DARTS-like 架构（cell 内无局部聚类）；当 `N_m > 1` 时，cell 内节点形成局部簇，有助于减少内存消耗
- **搜索范围含义**：`N_m = 1` 时 cell 退化为单节点（共 8 个超参数）；`N_m > 1` 时 cell 可包含最多 10 个内部节点

### 底层 (Bottom Level) — Operation Graph
- **模型**：Watts–Strogatz (WS) 随机图
- **超参数**：`θ_bottom = [N_b, K_b, P_b]`
  - `N_b ∈ [3,10]`
  - `K_b ∈ [2,5]`
  - `P_b ∈ [0.1, 0.9]`
- **含义**：每个节点代表一个原子操作（conv 3×3, conv 5×5, pooling 等），边代表操作间的数据流

### 结构参数：Stage Ratio & Channel Ratio

| 参数 | 含义 | 论文设置 |
|------|------|----------|
| `θ_S` | 各 stage 的相对长度（归一化向量） | 固定为 `[0.33, 0.33, 0.33]` |
| `θ_C` | 各 stage 的相对通道数 | 固定为 `[1:2:4]` |
| `θ_M` | 合并策略的概率权重（加权求和/注意力加权/拼接） | 固定为求和 |
| `θ_op` | 原子操作的类别概率 | 固定为仅 conv 3×3 |

**总搜索空间**：`Θ = [θ_top, θ_mid, θ_bottom, θ_S, θ_C, θ_M, θ_op]`，主实验仅搜索前 8 个图超参数。

### 搜索空间表达能力

- **总网络数** > 4.58 × 10⁵⁶（vs DARTS 的 8¹⁴ ≈ 4.40 × 10¹²）
- **架构节点总数范围**：[9, 1000]（vs RNAG 的 [30, 120]）
- **可表达子空间**：
  - RNAG (Xie et al., 2019)：`N_t=3, N_m=1, N_b=32` → 三级前馈 WS 图
  - DARTS-like：`N_t=20（前馈）, N_m=1` → 20 个相同 cell 级联
- **内存消耗范围**远大于 RNAG 和 DARTS 搜索空间（附录 Fig. 7）

## 5.2 网络生成过程

对于给定的超参数 `Θ`：

1. 按 `θ_top` 采样顶层 WS 图 → 确定 stage 数量和各 stage 间的接线
2. 按 `θ_S` 将顶层节点分配到 3 个 stage（如 20 个节点按 [0.2, 0.2, 0.6] 分配）
3. 对每个顶层节点，按 `θ_mid` 采样中层 ER 图 → 确定该 cell 内的节点和连接
4. 对每个中层节点，按 `θ_bottom` 采样底层 WS 图 → 确定该操作单元的具体计算图
5. 按 `θ_C` 为每个 stage 分配通道数
6. 按 `θ_M` 为每个节点采样合并策略（处理多输入时的融合方式）
7. 按 `θ_op` 为每个底层节点采样原子操作

**合并机制**：当多条边汇入同一节点时：
1. 所有激活通过池化降采样到最小张量的分辨率
2. 用 1×1 卷积统一通道数
3. 按 `θ_M` 采样的策略合并（加权求和 / 注意力加权 / 拼接）

## 5.3 搜索策略：贝叶斯优化

### 为什么 BO 适合 NAGO？

核心原因：**HNAG 将 NAS 从高维离散优化变为低维（8 维）连续优化**。传统 NAS 搜索空间有数百维的离散选择（每个边选一种操作），而 HNAG 仅需优化 8 个连续超参数——这正是 BO 最擅长的场景。

### BOHB（多保真度 BO）

采用 Falkner et al. (2018) 的 BOHB 框架，这是一个成熟的多保真度超参数优化方法，在原 [[randomly-wired-networks]] 中未被使用（RNAG 未做任何优化）：
- **原理**：用部分训练预算（少 epoch）评估大量配置，快速排除差配置；仅对好配置投入完整训练预算
- **三层预算**：CIFAR 上用 30/60/120 epochs，SPORT8 上用 100/200/400 epochs
- **设定**：60 次 BOHB 迭代，`η = 2`（Successive Halving 的淘汰率）
- **评估**：每次仅采样 1 个架构来评估生成器性能（基于"同生成器的架构性能相似"假设）
- **搜索成本**：CIFAR-10 约 12.8 GPU-days

**高排名相关性验证**：60 epochs 和 120 epochs 之间的 Spearman ρ = 0.82 → 低预算评估可靠。

### MOBO（多目标 BO）

采用 Belakaria et al. (2020) 的多目标 BO + 两处关键修改：

#### 修改 1：异方差 BNN 代理模型
- **动机**：图 2 显示不同生成器超参数下的性能方差差异显著（heteroscedastic noise）
- **实现**：3 层全连接 BNN（每层 10 神经元），两个输出头——预测均值 `μ` 和噪声方差 `w²_n(Θ)`
- **推理**：SGHMC 采样 100 组权重后验 `(w_f, w_n)`，近似预测后验均值和方差
- **效果**：NLL 远低于同方差 BNN（CIFAR-10: 3.43 vs 5.92; CIFAR-100: 0.89 vs 7.15）

#### 修改 2：并行批次评估
- **机制**：Local Penalisation (González et al., 2016; Alvi et al., 2019)
- **做法**：每轮 BO 推荐 B=8 个配置，对已选点的邻域施加惩罚函数，迫使新推荐点探索不同区域
- **惩罚函数**：`φ(Θ|Θ_j) = L‖Θ-Θ_j‖ / |μ(f|Θ)-M| + σ(f|Θ)`
  - `L`：目标函数的近似 Lipschitz 常数
  - `M`：当前最优观测值

### 完整算法流程

```
输入: 网络生成器 G, BO 代理模型 p(f|Θ,D), 采集函数 α(Θ|D)
for t = 1 to T:
    推荐 {Θ_j} = arg max α(Θ|D)  [B=1 for BOHB, B=8 for MOBO]
    for j = 1 to B in parallel:
        从 G(Θ_j) 采样 1 个架构 → 训练并评估验证性能 f_j
    用 {Θ_j, f_j} 更新数据集 D 和代理模型
返回: 最优 Θ* 或 Pareto 集 Θ*
最终: 从 G(Θ*) 采样 8 个架构，完整训练（600 epochs），报告测试性能
```

## 5.4 HNAG vs RNAG 对比

| 维度 | HNAG (本文) | RNAG (Xie et al., 2019) |
|------|-------------|------------------------|
| 结构 | **三级层次图** | 三级顺序平面图 |
| 中层 | ER 图（允许 N=1） | WS 图（N≥3） |
| 跨 stage 连接 | ✅ 顶层直接跨 stage | ❌ 纯前馈 |
| 设计空间大小 | >4.58×10⁵⁶ | 远小 |
| 节点数范围 | [9, 1000] | [30, 120] |
| 不同分辨率输入 | ✅ 同一节点接收不同 stage 的特征 | ❌ 同 stage 内固定分辨率 |
| 优化 | ✅ BO 自动优化 | ❌ 手工设定 |
