# NequIP 批判分析与迁移

## 1. 主要贡献

1. 提出面向原子势的 E(3) 等变消息传递架构，使网络内部特征具有明确的几何变换规律；
2. 将势能预测与自动微分结合，从结构上保证原子力来自同一势函数；
3. 证明等变张量特征可显著降低高成本第一性原理标签需求；
4. 在分子、周期材料、反应界面和离子输运上展示统一模型；
5. 用旋转阶数消融和学习曲线分析，把性能提升与等变表示联系起来；
6. 提供开源代码、输入文件和部分数据，为后续 [[allegro]] 与 [[sevennet]] 奠定基础。

## 2. 核心知识点

### 2.1 等变表示比“数据增强后再学不变性”更直接

旋转、反射和平移规律是已知物理先验。NequIP 通过不可约表示和张量积把这些规律固化进网络，使模型只需学习与坐标系无关的物理关系。

### 2.2 标量输出可以来自张量内部状态

总势能必须是标量，但内部表示不必全是标量。方向性张量能保留邻域几何信息，再通过允许的张量积路径最终收缩到标量输出。

### 2.3 守恒性来自输出参数化

NequIP 并不是通过一个额外损失“鼓励”力场守恒，而是先输出势能，再对坐标求导。这种结构约束通常比软惩罚更可靠。

### 2.4 高精度与高扩展性不是同一个问题

NequIP 主要解决表示精度和样本效率。多层消息传递会扩大有效感受野，分布式并行与大规模推理仍需额外系统设计。

## 3. Negative Knowledge

### 3.1 长程相互作用仍未解决

固定 cutoff 和有限层消息传递不能系统表示超出有效感受野的静电、色散、弹性或其他长程项。消息传递可能隐式吸收部分影响，但没有完整物理保证。

### 3.2 解释性有限

每原子能量与内部通道是可训练分解，不等价于唯一的二体、三体、静电或范德华物理项。低预测误差不能自动提供可解释的相互作用机制。

### 3.3 超参数高度任务相关

cutoff、层数、最大旋转阶、奇偶性、通道数、邻居归一化以及能量/力损失权重都影响结果。论文没有给出可跨体系直接复用的自动选型规则。

### 3.4 等变性不是完整物理正确性

E(3) 等变只保证坐标变换一致性，不能保证：

- 训练分布覆盖稀有状态；
- 反应势垒正确；
- 长时积分稳定；
- 材料相变和失稳路径完整；
- 外推相态和化学组分可靠。

### 3.5 消息传递带来并行瓶颈

随着层数增加，有效感受野扩大。空间分区时，要么扩大 ghost 区域并产生冗余计算，要么像 [[sevennet]] 一样在每层交换节点特征和反向梯度。

### 3.6 原论文归一化策略需谨慎迁移

对固定尺寸体系减去训练集平均总能量可行，但在变尺寸体系中可能破坏尺寸广延性。迁移到不同规模结构时，应优先使用按原子/节点或按组分的可扩展基准能量。

## 4. 与 Allegro、SevenNet 的关系

| 路线 | 保留内容 | 主要改变 | 解决问题 |
|---|---|---|---|
| NequIP | E(3) 等变张量消息传递 | 原始基础架构 | 精度与数据效率 |
| [[allegro]] | 等变张量积与能量一致性 | 改为严格局部 pair-centered 表示 | 超大规模扩展性 |
| [[sevennet]] | NequIP 类 atom-centered message passing | 增加逐层正反向通信 | 多 GPU 空间分解 |

三者不是简单的“新模型淘汰旧模型”，而是针对表示、局部性和并行系统的不同取舍。

## 5. 可迁移到结构动力学的知识

| NequIP 经验 | 结构动力迁移方式 |
|---|---|
| 标量/向量/张量按变换规律组织 | 位移、速度、力、弯矩、转角和局部轴分别编码 |
| 球谐方向基 | 表示梁柱方向、构件夹角和空间连接 |
| 等变张量积 | 学习方向相关的多构件耦合，而非只用标量邻接权 |
| 每原子能量求和 | 建立构件、节点或子结构局部势能分解 |
| 势能梯度得到力 | 由可微能量得到恢复力，减少非守恒预测 |
| cutoff 邻域 | 子结构局部计算与固定通信范围 |
| 消息传递 | 与 MechConv 的矩阵边权和状态传播结合 |
| 任务相关损失权重 | 对位移、速度、内力、平衡和能量损失进行尺度归一化 |

## 6. 迁移时不能机械照搬的部分

### 6.1 对称群不同

原子体系通常可假设整体平移、旋转和反射不改变能量。建筑结构存在：

- 固定支座；
- 重力方向；
- 截面局部轴；
- 材料各向异性；
- 边界条件和荷载方向。

因此应定义适合具体结构问题的 SE(2)、SE(3)、局部坐标协变或受约束等变，而不是无条件采用完整 E(3)。

### 6.2 原子邻域与构件拓扑不同

原子图通常由空间 cutoff 构建；结构图的连接由构件、节点、约束与力学传递路径决定。几何接近并不代表存在结构连接，远距离节点也可能通过刚性楼板或约束发生强耦合。

### 6.3 势能模型不能覆盖所有非保守行为

阻尼、塑性耗能、损伤、摩擦和路径相关本构不能只由单值势能描述。更合理的结构模型应包含：

$$
f_{int}=f_{el}(x)+f_{hist}(x,z),
$$

并为历史变量 $z$ 设计可替换本构更新模块。

## 7. 面向用户研究的具体研究机会

1. **等变 MechConv：** 在矩阵边权聚合中显式编码构件局部轴和旋转变换；
2. **能量—本构双模块：** 弹性部分由势能梯度得到，非线性耗散部分由可替换历史变量模块给出；
3. **NequIP vs Allegro 路线比较：** 比较多跳消息传递与严格局部高阶张量表示在百至千自由度结构上的精度、显存和通信成本；
4. **SevenNet 式子图并行：** 每层只交换边界节点状态与反向梯度，使大结构可拆成子图训练；
5. **全局平衡兜底：** 始终施加 $M\ddot x+C\dot x+f_{int}=F$，防止局部等变网络产生全局不平衡；
6. **频率覆盖：** 将结构模态、Fourier 特征或时频编码与等变空间骨干结合，避免只学到低频响应；
7. **最坏任务搜索：** 用 [[kolmogorov-n-width-piml]] 检查高频、近屈服和跨结构任务是否被平均误差掩盖；
8. **局部—全局混合：** 局部非线性采用 Allegro 式严格局部表示，长程模态或刚性楼板耦合采用显式全局算子。

## 8. 结论性评价

NequIP 的真正启发不是“把一个原子势模型直接换到结构图上”，而是三条设计原则：

1. 已知几何变换规律应写入表示；
2. 守恒量应通过输出参数化保证，而非只依赖软损失；
3. 精度、局部性和分布式扩展性应分开设计并联合评估。
