# A New ParaDiag Time-Parallel Time Integration Method

论文利用离散时间矩阵的“循环矩阵 + 低秩修正”结构，通过 FFT、Sherman-Morrison-Woodbury 和投影 Krylov 方法实现时间并行，并讨论 α-circulant 加速及高阶 BDF 推广。^[raw/papers/gander2024-new-paradiag.pdf]

对 V20 的价值在于：因果初值边界不能通过纯循环近似忽略；要么保留低秩修正，要么使用有明确混叠误差界的单边 z 变换。V20 选择后一条路线，并把 `ρ^L` 作为正式审计量。
