# An Accurate and Time-Parallel Rational Exponential Integrator

REXII 用一组互相独立的复移位线性系统近似 `exp(tA)`，面向虚谱线性双曲/振荡系统，并用 GPU 同时并行有理项和空间计算。^[raw/papers/caliari2021-rexii.pdf]

它直接支持 V20 的“复移位结构系统可在 GPU 并行”判断，但它只处理线性矩阵指数。V20 必须把非线性本构隔离到四阶段力插件，不能把完整 Bouc-Wen 动力学误称为 REXII 可解。
