# Mamba-3

## Definition

Mamba-3 is a state space sequence model improving linear-time sequence modeling through:

- exponential-trapezoidal discretization;
- complex-valued state transitions;
- MIMO state updates.

## Relations

- Parent: State Space Model (SSM)
- Related: Mamba-2, Mamba, neural operator, sequence modeling

## Structural Dynamics Relevance

Potentially useful as a temporal state evolution module combined with:

- MechConv spatial operators;
- physics-informed residual constraints;
- large-scale structural response prediction.
